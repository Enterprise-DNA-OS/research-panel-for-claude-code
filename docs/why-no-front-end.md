# Views without a front end

The operator asks for panel readiness, cohort gaps and the week's interviews. The commands read the database and render private HTML snapshots through npm run view. npm run docs renders study briefs, consent evidence records and incentive reconciliations. Change brand.json to use your business name, logo and colours.

Snapshots do not edit records. A browser product can give participants self-service booking, mobile forms, consent signing, calendar availability, access roles and live updates. Those require additional implementation. Enterprise DNA can build and run those parts in your version. The free base assumes a trusted operator and supplied evidence. It neither records interviews nor sends invitations nor pays incentives.

The ten questions in the README are demonstrated here. They are not a claim that the incumbent lacks matching reports. Great Question already has rules, reporting and conversational access. Ownership and editable business rules are the reasons to use this database.
