# compliance

Check notice, retention and consent evidence with source references.

```bash
npm run panel -- compliance
```

Options: --json only. Every command accepts --json.

Read before changing records. Resolve ambiguous references by listing matches. Report actual rows and empty results honestly. Add --json when another process needs the output. Open docs/compliance.md. Flag findings as evidence or policy checks, never legal certification. The configured periods are business policies.
