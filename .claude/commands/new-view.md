# Add a read-only view

Start with the question the operator needs answered and the existing views. Add a SQL view through a new migration if required. Add a read-only SELECT section to views.json, using the shared renderer and brand.json. Exclude personal information not needed for the question. Run npm test and npm run view. Open the HTML, check the figures against the CLI and return the private file path. No server, editing controls or public link.
